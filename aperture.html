Lightyear Aperture · the open verifier

Don’t trust us. Check the evidence yourself.

Aperture is a small, free verifier anyone outside Lightyear can run. Point it at an evidence pack and it checks, offline, that every result is exactly what we say it is.

What it checks

Four checks, run on your machine, against keys you choose to trust.

Manifest hashes match

Every file in the pack is exactly the file the record names, byte for byte.

Receipt digests recomputed

Aperture recomputes each receipt’s digest itself instead of trusting the number written in it.

Signatures checked against your keys

Signatures are verified against key fingerprints you obtained separately, not keys shipped in the pack.

Hash chain unbroken

Each record links to the one before it, so a missing, reordered or edited entry shows.

Four answers, one pass

It says “incomplete” rather than guessing.

PASS · EXIT 0

Every check ran, every one passed, and each is anchored to a key you trust.

FAIL · EXIT 1

Something does not match. Aperture names the file or record.

INCOMPLETE · EXIT 3

There was nothing it could anchor. No pass is given on missing evidence.

UNANCHORED

The checks ran, but you supplied no key to anchor them to, so it cannot pass.

Built for people who don’t trust us

Small enough to read. Strict enough to rely on.

An auditor, a regulator, your own engineers or an investor’s diligence team can run it without installing anything of ours and without a network connection.

  • Standard-library Python only; nothing to install
  • Works offline; never calls home
  • Never runs Lightyear’s code
  • Free and open
  • You pin the keys; the pack cannot vouch for itself
